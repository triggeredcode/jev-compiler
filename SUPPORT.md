# Support

Start with the [README](README.md), [quickstart](docs/quickstart.md), and
[architecture guide](docs/architecture.md).

Use the repository's [issue chooser](https://github.com/triggeredcode/jev-compiler/issues/new/choose)
for reproducible bugs and focused feature requests. Include the release tag or commit, a minimal safe
reproduction, and environment details. Remove API keys, private decision policies, recordings, and
provider responses.

Security vulnerabilities and sensitive reports must use the private process in
[SECURITY.md](SECURITY.md), not a public issue.

The project is currently maintained on a best-effort basis. Public support does not include private
policy review, credential recovery, provider account support, or guarantees for alpha releases.
